# **App Name**: IdeaSpark

## Core Features:

- AI-Powered Prompt Generation: Generate unique and creative prompts for writing, art, or daily inspiration based on selected themes, using an AI tool.
- Category Selection: Allow users to select categories or themes (e.g., 'Writing', 'Art', 'Daily Challenge') to guide the prompt generation process.
- Prompt Display: Clearly display the generated prompt to the user in an easy-to-read format.
- Save Prompt: Enable users to save their favorite prompts for future reference.
- View Saved Prompts: A dedicated section where users can browse and manage all their previously saved prompts.
- Share Prompt: Provide an option to easily share generated or saved prompts with others.

## Style Guidelines:

- Primary color: A deep, calming blue (#2458AB) representing depth of thought and clarity, contrasting with the light background for readability.
- Background color: A very light, subtle blue-gray (#EBF0F7) to create a serene and inspiring atmosphere.
- Accent color: A vibrant lavender (#C699FB) to signify creativity, spark, and highlight interactive elements.
- Headline and body font: 'Inter' (sans-serif) for its modern, clear, and objective readability, suitable for presenting creative prompts concisely.
- Utilize minimalist, line-art style icons related to ideas, creativity, and thought processes (e.g., lightbulbs, thought bubbles, pen/brush strokes).
- Implement a clean, uncluttered layout with ample white space, focusing on a card-based display for prompts to enhance readability and user focus.
- Incorporate subtle animations for UI feedback, such as gentle fade-ins when new prompts are generated or hover effects on interactive elements.
